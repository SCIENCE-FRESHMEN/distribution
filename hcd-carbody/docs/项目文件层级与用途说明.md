# 项目文件层级与用途说明

以下按 `D:\hcdcarbody` 的实际目录说明文件用途。标记 `[API]` 表示服务运行时直接使用，`[仿真]` 表示仅用于命令行仿真，`[共用]` 表示两种运行方式共用，`[工具]` 表示构建、检查或调试脚本，`[生成物]` 表示可重新生成的输出。

```text

├── config_loader.py                   [共用] JSON/JSONC 配置读取器。

├── run.py                             [仿真] 单次事件驱动仿真入口。
├── run_compare.py                     [仿真] 标准四策略组合对比入口。
├── run_compare_scaled_warehouse.py    [仿真] 扩展仓库规模的对比入口。

│   ├── main.py                        [API] 创建 FastAPI 应用、注册路由和管理生命周期。

│   ├── routes/                        [API] 入库、计划、调度和反馈路由。

├── config/
│   ├── warehouse.json                 [共用] 仓库结构、巷道映射、匹配和评分参数。
│   ├── time_estimator.json            [共用] 堆垛机路径与运动学估时参数。
│   └── 配置参数说明.md                 [共用] 配置字段、类型、示例和生效范围说明。

│   ├── API接口说明.md                  [API] 当前 REST API 的字段、用法和示例。
```

API 链路：`run_api.py -> api/main.py -> api/services/warehouse_service.py -> simulation/warehouse_core.py`，并使用 `allocation/`、`schedule/`、`estimate/`、`config_loader.py` 和 `config/`。

仿真链路：`run.py`、`run_compare.py` 或 `run_compare_scaled_warehouse.py -> simulation/warehouse_core.py`，并使用 `allocation/`、`schedule/`、`estimate/`、`config/warehouse.json` 和仿真输入数据；日志和图表均为输出。
