# 项目文件层级与用途说明

以下按 `D:\hcd` 当前实际路径顺序列出。`[API]` 表示 API 服务直接使用，`[仿真]` 表示仅命令行仿真使用，`[共用]` 表示两者共用，`[工具]` 表示辅助脚本或资料，`[生成物]` 表示可重新生成的输出。

```text

├── .gitignore                         [共用] Git 忽略规则；仅保留 API 初始 BOM 配置。
├── README.md                          [共用] 项目简介和基础仿真运行说明。
├── requirements.txt                   [共用] API、仿真、估时和图表的 Python 依赖。
├── config_loader.py                   [共用] JSON/JSONC 读取器。
├── run_api.py                         [API] Uvicorn 启动入口。
├── run.py                             [仿真] 单次事件驱动仿真入口。
├── run_daily.py                       [仿真] 按日期批量仿真入口。
├── run_compare.py                     [仿真] 四种策略组合的并行对比入口。
├── visualize_results.py               [仿真] 策略对比日志图表生成器。
├── visualize_daily_results.py         [仿真] 按日仿真日志图表生成器。
├── plot_gantt_from_log.py             [仿真/工具] 从日志生成任务甘特图。
│

│   ├── baseline_strategy.py           [仿真] 基线巷道/货位策略，用于策略对照。
│   └── proposed_strategy.py           [共用] 改进分配，处理配对、属性、禁用位、模拟占位和产线约束。
├── api/
│   ├── __init__.py                    [API] API 包入口。
│   ├── main.py                        [API] 创建应用、注册路由和管理生命周期。
│   ├── models.py                      [API] 请求/响应 Pydantic 模型。
│   ├── state.py                       [API] 下发任务的 pending/confirmed/timeout 反馈状态机。
│   ├── routes/
│   │   ├── __init__.py                [API] 路由包入口。
│   │   ├── bom.py                     [API] BOM 查询和更新接口。
│   │   ├── feedback.py                [API] EXECUTING、COMPLETED、FAILED 反馈接口。
│   │   ├── inbound.py                 [API] 入库推荐和调整接口。
│   │   └── schedule.py                [API] mixed、未确认和可执行任务接口。
│   └── services/
│       ├── __init__.py                [API] 服务包入口。

│   ├── pyinstaller/hcd-api/           [API/生成物] PyInstaller 分析与缓存结果。

├── config/
│   ├── warehouse.json                 [共用] 仓库、资源时间、禁用位、产线映射和评分权重。
│   ├── time_estimator.json            [共用] 堆垛机路径和运动学估时参数。
│   ├── sku_config.json                [API] API 初始 BOM；仿真不读取该文件。
│   └── 配置参数说明.md                 [共用] 配置字段、示例和生效范围说明。
├── docs/
│   ├── 项目文件层级与用途说明.md       [共用] 本文件。

│   ├── Apifox测试用例.md               [API/工具] Apifox 测试用例。
│   ├── API程序打包与部署说明.md         [API/工具] 打包、配置、启动和卸载说明。
│   ├── 调度评分与巷道分配说明.txt       [共用] 优化评分与改进分配算法说明。
│   ├── 巷道货位与调度策略伪代码.md       [共用] 主要算法分支的中文伪代码。

│   └── 纵梁库_策略流程图说明.md         [共用] 巷道、货位和调度的总体及详细流程图。
├── estimate/
```

API 链路：`run_api.py -> api/main.py -> api/services/warehouse_service.py -> simulation/warehouse_core.py`，并使用 `allocation/`、`schedule/`、`estimate/`、`config_loader.py` 和 `config/`。

仿真链路：`run.py`、`run_daily.py` 或 `run_compare.py -> simulation/warehouse_core.py`，并使用 `allocation/`、`schedule/`、`estimate/`、`config/warehouse.json`、`config/time_estimator.json` 和 `simulation/data/`；日志和图表均为输出。
